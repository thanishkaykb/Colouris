# 🎨 Colouris

A color-memory game that quietly humbles your confidence in remembering colors.

**Colouris** challenges players to memorize a set of randomly generated colors and recreate them using color controls. It blends design, perception, and a tiny bit of chaos into a fun interactive experience that reveals how unreliable human color memory actually is. Built with a modern frontend stack and designed for a smooth, minimalist experience.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/thanishkaykb/Colouris.git
```

### Navigate to the project

```bash
cd Colouris
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

The application will start locally at:

```bash
http://localhost:5173
```

## 🎮 How to Play

1. Observe the displayed colors carefully.
2. Memorize each color before it disappears.
3. Use the color controls to recreate the original colors.
4. Submit your guesses.
5. Receive a score based on how accurately you matched each color.
6. Challenge yourself to beat your previous score.

## 🎯 Purpose

Most people assume they can remember colors accurately for a few seconds.

Colouris exists to prove otherwise.

The project explores visual memory through an engaging game experience, showing how difficult it is to recall exact shades, saturation levels, and brightness values even moments after seeing them. What starts as a simple challenge quickly turns into a fascinating experiment in perception. ([Lovable App][1])
